# Upstream issue records

No upstream runtime defect was reproduced during the 1.0.0 implementation. Known
packaging, provenance, architecture, external-service, and obsolete-dependency
limitations are recorded per manifest and in the catalogue review.

When a defect is reproduced, add one sanitized document here with project/version,
platform, exact minimal commands, bounded logs, expected versus actual behavior,
official issue-tracker search results, classification, proposed smallest patch,
tests, reversibility, and intentional-vulnerability revalidation. Do not fork or
open an upstream issue or pull request without explicit authorization.
